# Atelier 5 : Plan d'Action d'Adoption de l'IA

**Durée estimée :** 15 minutes  
**Type :** Travail individuel ou en binôme

## 🎯 Objectif
Ne pas repartir de cette formation les mains vides. Formaliser LA stratégie conrète que vous allez mettre en place dès demain pour booster votre carrière et votre équipe.

---

## 🛠️ Instructions

Prenez 5 à 10 minutes pour remplir ce court document de stratégie personnelle.
*(Vous pouvez le faire dans un bloc-notes ou en équipe sur un tableau blanc).*

### 🌅 Horizon 1 : Cette Semaine (Quick Wins)
- Quelle est la **première tâche** rébarbative que je vais déléguer à un LLM (Copilot, Claude) dès demain ? (Ex: Générer un DTO, écrire mes messages de commit, documenter ma fonction).
  - Tâche 1 : `______________`
  - Avez-vous besoin d'un prompt particulier à sauvegarder ?

### 🏞️ Horizon 2 : Ce Mois-ci (Changement d'Habitude)
- Comment allez-vous intégrer l'IA dans votre outil de développement central (Ex: Installation de Cursor IDE ou abonnement Github Copilot complet) ?
  - Mon outil IA principal va être : `______________`
- Dans quel espace partagerez-vous vos meilleurs "Prompts" avec l'équipe ? (Ex: Base de connaissances Notion/Confluence ou Slack).

### 🏔️ Horizon 3 : Ce Trimestre (Agentic AI - Automatisation)
- Quelle partie complexe du cycle de vie logiciel (CI/CD) aimeriez-vous confier à un Agent IA autonome dans votre entreprise ?
  - [ ] Les revues de code automatiques (PR Review bots)
  - [ ] La génération semi-automatisée d'une suite de Tests E2E
  - [ ] L'envoi de rapports "Release Notes" rédigés automatiquement sur Slack
- Qui devez-vous convaincre pour y parvenir (Sécurité, DevOps, Lead Dev) et comment allez-vous garantir l'absence de fuite de Propriété Intellectuelle (IP) ?

---

## 📝 Conclusion
L'IA Remplacera-t-elle les codeurs ? Probablement pas tout de suite. Mais **un développeur qui utilise l'IA remplacera assurément un développeur qui ne l'utilise pas.**

**Bonne implémentation !**
