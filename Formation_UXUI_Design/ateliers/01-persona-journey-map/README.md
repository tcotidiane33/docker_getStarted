# Atelier 1 : Persona et User Journey Map (UCD)

**Durée estimée :** 20 minutes  
**Type :** UX Research / Atelier métier

## 🎯 Objectif
Savoir synthétiser des résultats de recherche utilisateur pour créer des **Personas** viables et modéliser une **User Journey Map** (parcours utilisateur).

---

## 🛠️ Instructions

### Étape 1 : Création du Persona
Développons un produit : **Une application de productivité (time-tracking et facturation) pour les développeurs freelances.**

Définissez le Persona "Julien, le Développeur Freelance". Remplissez les cases suivantes :
1. **Données Démographiques :** Âge, localisation, métier, ancienneté.
2. **Objectifs principaux :** Que cherche-t-il à accomplir ave application ?
3. **Frustrations actuelles (Pain points) :** Quels sont ses problèmes avec Excel ou les outils existants ?
4. **Citation / Devise :** Une phrase résumant sa mentalité.

### Étape 2 : User Journey Map (Le Parcours)
Définissons les étapes par lesquelles Julien passe pour facturer son client en fin de mois. Tracez un tableau sur la base de ces 5 phases :

| Phase | 1. Réalisation du travail | 2. Saisie du temps | 3. Génération facture | 4. Envoi client | 5. Suivi du paiement |
|:---|:---|:---|:---|:---|:---|
| **Actions** | *Code toute la journée...* | | | | |
| **Touchpoints** (Outils) | IDE, Slack | | | | |
| **Émotions** (Courbe) | 😐 Mode focus | | | | |
| **Pain Points** (Frictions) | Oublie de lancer le timer | | | | |

*Complétez ce tableau avec ce que Julien vit, pense et fait pendant chaque étape.*

### Étape 3 : Identifier les Opportunités
En observant votre User Journey Map et les "Pain Points" identifiés, trouvez **3 fonctionnalités UX** qui pourraient résoudre la majorité des frictions de Julien.

---

## 📝 Livrable attendu
- Le profil complet du Persona sur papier, FigJam ou Miro.
- La carte du parcours complet avec au moins un point de frustration mis en évidence par de potentielles fonctionnalités correctrices.
