# Atelier 5 : Tests Utilisateurs & Heuristiques de Nielsen

**Durée estimée :** 30 minutes  
**Type :** Test UX Critique

## 🎯 Objectif
Utiliser la grille objective inventée par Jakob Nielsen pour auditer une interface du marché. Apprendre à structurer une session "Test Utilisateur" en direct dans votre entreprise.

---

## 🛠️ Instructions

### Étape 1 : Les Heuristiques de Nielsen (L'Audit Externe)
Prenez une application web que vous utilisez souvent (ex: un site d'e-commerce obscur, l'intranet de votre entreprise, ou même un menu d'options de smartphone).

Auditez-la en reprenant au hasard ces 3 des 10 lois fondamentales de Nielsen :
1. **Loi n°1 (Visibilité de l'état système)** : Est-ce qu'une barre de progression vous indique exactement où se situe l'application ou êtes-vous bloqué face à un chargement non identifié ?
2. **Loi n°3 (Permettre d'annuler/Refaire)** : Y a-t-il le fameux bouton "Bouton d'Urgence" si vous cliquez sur un bouton de trop ?
3. **Loi n°4 (Consistance)** : Les boutons "Submit" sont-ils de la même couleur sur chaque page ou le site est-il inconstant ?

*Documentez vos trouvailles dans un document avec des captures d'écran encerclant les "frictions heuristiques".*

### Étape 2 : Rédiger un Protocole de Test Utilisateur Réel
Votre équipe lance un nouveau "Menu de commande" (Checkout). Réalisons un test non pas sur votre design final, mais avec la méthode du "Pensée à Voix Haute" (Think Aloud).

Rédigez le script d'introduction d'un Test (Maximum 5 minutes). Devront y figurer les mentions suivantes à adresser au testeur (utilisateur) :
1. "Nous testons l'interface, nous ne vous testons **pas vous**."
2. "Il n'y a pas de mauvaise réponse."
3. Un scénario de mise en situation : *"Imagine que tu es pressé à la gare et que tu cherches à ajouter tes écouteurs préférés au bon d'achat..."* (Laisser agir, ne pas mâcher l'action technique).

### Étape 3 : Plan d'Action d'Équipe Continuer (Horizon J+7/30/90)
1. Listez la chose principale que vous modifierez dès "lundi" dans vos workflows (ex: Utiliser les Auto Layout si ce n'était pas le cas, Installer Figma Contrast Checker).
2. Ce semestre : Proposez la création d'un "Design System" unifié à l'équipe Dev Frontend.
